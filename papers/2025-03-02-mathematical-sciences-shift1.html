ID 705101Q1. A monkey covers exactly 10 m on ground in each jump. What is the least number of jumps required to reach a distance 1 m away from where the monkey jumps first?
  1. 1
  2. 2
  3. 3
  4. 9
Show step-by-step solution

Answer: (2)

What is given. Every jump is a straight-line displacement of length exactly $10$ m, in any direction on the ground. The required net displacement is $1$ m.
Idea used. Jumps are vectors in a plane. The resultant of two vectors of equal length $\ell$ can have any magnitude in $[0,\,2\ell]$, so two jumps already reach every distance up to $20$ m.
  1. One jump is impossible. A single jump lands exactly $10$ m away, and $10\neq 1$.
  2. Two jumps can work. Let the jumps be $\vec{u}$ and $\vec{v}$ with $|\vec u|=|\vec v|=10$ and angle $\theta$ between them. Then $$|\vec u+\vec v|=\sqrt{10^2+10^2+2(10)(10)\cos\theta}=20\left|\cos\tfrac{\theta}{2}\right|.$$
  3. Solve for the required angle. Setting $20\left|\cos\tfrac{\theta}{2}\right| = 1$ gives $\cos\tfrac{\theta}{2}=\tfrac{1}{20}$, so $\theta = 2\cos^{-1}(0.05)\approx 174.3^\circ$. This angle exists, so the monkey lands exactly $1$ m from its start.

Two jumps suffice and one does not, so the least number is 2, option (2).

Common slip. Reading the jump as one-dimensional, forward and backward only. Then $10-10=0$ and $10+10=20$ are the only two-jump distances and the answer looks impossible. The monkey moves on a plane, so any angle is available.

ID 705102Q2. Cube root of $0.0125\%$ is closest to
  1. $0.005\%$
  2. $0.05\%$
  3. $0.5\%$
  4. $5\%$
Show step-by-step solution

Answer: (4)

What is given. The number whose cube root is wanted is $0.0125\%$.
Idea used. Convert the percentage to a plain number first, take the cube root, then convert back to a percentage. Taking the cube root of the numeral while leaving the $\%$ sign attached is what makes this question a trap.
  1. Write the percentage as a number. $0.0125\% = \dfrac{0.0125}{100} = 1.25\times 10^{-4} = 125\times 10^{-6}$.
  2. Take the cube root. $\sqrt[3]{125\times10^{-6}} = \sqrt[3]{125}\times 10^{-2} = 5\times 10^{-2} = 0.05$.
  3. Convert back to a percentage. $0.05 = \dfrac{5}{100} = 5\%$.
  4. Check. $(0.05)^3 = 0.000125 = 0.0125\%$, which is the original number.

The cube root is $5\%$, option (4).

Common slip. Cube-rooting $0.0125$ to get $0.232$ and then hunting for the nearest option, or answering $0.05\%$ because $0.05$ appeared during the working. The $0.05$ is the plain number; as a percentage it is $5\%$.

ID 705103Q3. How many 5-digit numbers, using 0 to 9, can be generated such that ‘123’ appears as a string and no digit appears more than once?
  1. 228
  2. 108
  3. 156
  4. 114
Show step-by-step solution

Answer: (4)

What is given. Five-digit numbers with all digits distinct, containing the block $123$ in consecutive positions. A five-digit number cannot begin with $0$.
Idea used. Glue $1$, $2$, $3$ into a single block and count where the block can sit. The two free positions are filled from the seven unused digits, with the leading-zero restriction applied only when a free digit occupies position one.
  1. Set up. The block $123$ occupies three consecutive positions, so it starts at position $1$, $2$ or $3$. The remaining two positions are filled from $\{0,4,5,6,7,8,9\}$, seven digits, without repetition.
  2. Block at positions 1–3. The number reads $1\,2\,3\,\_\,\_$ and already starts with $1$, so no leading-zero issue. The two free places give $7\times 6 = 42$ numbers.
  3. Block at positions 2–4. The number reads $\_\,1\,2\,3\,\_$. Position $1$ must not be $0$, leaving $6$ choices; position $5$ takes any of the $6$ digits still unused. That is $6\times 6 = 36$.
  4. Block at positions 3–5. The number reads $\_\,\_\,1\,2\,3$. Again position $1$ has $6$ choices and position $2$ has $6$: another $36$.
  5. Add. $42+36+36 = 114$. No number is counted twice, because all digits are distinct so the block $123$ cannot occur in two places at once.

There are 114 such numbers, option (4).

Common slip. Forgetting that a five-digit number cannot start with $0$. Using $7\times 6=42$ for all three positions of the block gives $126$, which is not among the options.

ID 705104Q4. The diagrams show two orientations of a die having numbers 1 to 6 written on different faces. In the first the visible faces are $3$ on top, $4$ in front and $5$ on the right; in the second they are $4$ on top, $2$ in front and $5$ on the right. The number on the face opposite the face showing $3$
  1. is 2
  2. is 1
  3. is 6
  4. cannot be determined from the given data
Show step-by-step solution

Answer: (1)

What is given. View 1 shows top $=3$, front $=4$, right $=5$. View 2 shows top $=4$, front $=2$, right $=5$.
Idea used. The face $5$ is on the right in both views, so the second view is the first one rotated about the axis through $5$ and its opposite face. That rotation cycles top, front, bottom and back among themselves.
  1. Identify the axis. Both views show $5$ on the right, so the die has simply been turned about the left–right axis through the $5$ face. Under that turn the four faces top, front, bottom, back rotate in a cycle.
  2. Apply the rotation. Roll the die one quarter-turn towards the viewer, so front goes to top, bottom goes to front, back goes to bottom and top goes to back.
  3. Match the second view. After the turn the top is the old front, namely $4$, which is exactly what view 2 shows. So the turn is the right one, and view 2's front must be the old bottom.
  4. Read off the answer. View 2's front is $2$, so the old bottom is $2$. The old bottom is the face opposite the old top, and the old top was $3$.

The face opposite $3$ carries $2$, option (1).

Common slip. Assuming that because $4$ and $5$ are adjacent to $3$ the opposite face must be one of the unseen numbers $1$ or $6$. The number $2$ is never seen next to $3$ in either view precisely because it is hidden underneath.

ID 705105Q5. There are four containers of equal height, whose bases are a circle, a square, a rectangle and an equilateral triangle having the same area. Which one of the following statements about these containers is true?
  1. Their volumes are equal.
  2. Volume of the rectangular container is larger than that of the square container.
  3. Volume of the triangular container is smaller than that of the square container.
  4. Volume of the square container is larger than that of the circular container.
Show step-by-step solution

Answer: (1)

What is given. Four prisms of equal height whose base areas are all equal, though the base shapes differ.
Idea used. For any prism or cylinder, volume $=$ base area $\times$ height. The shape of the base never enters the formula.
  1. Write the volume. Each container is a prism (or a cylinder) of height $h$ on a base of area $A$, so its volume is $V = A\,h$.
  2. Use the hypotheses. The problem states that $h$ is the same for all four and that $A$ is the same for all four.
  3. Conclude. Since $V = Ah$ depends only on $A$ and $h$, all four volumes are equal, whatever the base shapes are.

All four volumes are equal, option (1). Options (2), (3) and (4) each claim a strict inequality, and every one of them is false.

Common slip. Confusing this with the isoperimetric fact that among shapes of equal perimeter the circle has the largest area. Here the areas are given as equal, so there is nothing left to compare.

ID 705106Q6. The diagrams show the rates of diamond and emerald in a range of sizes. For the diamond the price rises linearly from $0$ to $5$ lakh Rs per carat as the weight goes from $0$ to $2.5$ carat; for the emerald it rises linearly from $0$ to $2.5$ lakh Rs per carat over the same range. A person wants to buy a diamond and an emerald of identical size for a total of Rs. $6{,}75{,}000$. What is that size?
  1. 1 carat
  2. 1.5 carat
  3. 2 carat
  4. 2.5 carat
Show step-by-step solution

Answer: (2)

What is given. Both graphs plot price per carat against weight, and both pass through the origin as straight lines. At $2.5$ carat the diamond rate is $5$ lakh Rs/carat and the emerald rate is $2.5$ lakh Rs/carat.
Idea used. The $y$-axis is a rate, not a total. Cost $=$ rate $\times$ weight, so a rate that itself grows linearly with weight makes the cost grow as the square of the weight.
  1. Read the two rate laws. Both lines pass through the origin. Diamond: slope $=5/2.5=2$, so the rate is $2w$ lakh Rs per carat at weight $w$. Emerald: slope $=2.5/2.5=1$, so its rate is $w$ lakh Rs per carat.
  2. Turn rates into costs. Cost $=$ (rate) $\times$ (weight). Diamond costs $w\cdot 2w = 2w^2$ lakh Rs, emerald costs $w\cdot w = w^2$ lakh Rs.
  3. Form the equation. Total $= 2w^2 + w^2 = 3w^2$ lakh Rs, and Rs. $6{,}75{,}000 = 6.75$ lakh, so $3w^2 = 6.75$.
  4. Solve. $w^2 = 2.25$, hence $w = 1.5$ carat.

The common size is $1.5$ carat, option (2).

Common slip. Treating the $y$-axis as the total price and solving $2w + w = 6.75$, which gives $w = 2.25$ carat and matches no option. The axis label reads Lakh Rs per carat.

ID 705107Q7. If A is B’s daughter, B is C’s brother and D is C’s father, then what is A to D?
  1. Grandfather
  2. Grandmother
  3. Grandson
  4. Granddaughter
Show step-by-step solution

Answer: (4)

What is given. A is the daughter of B; B is the brother of C; D is the father of C.
Idea used. Work up the chain one link at a time, and keep track of the gender that each stated relation forces.
  1. B and C are siblings. B is C’s brother, so they share the same parents.
  2. D is B’s father too. D is C’s father, and since B is C’s sibling, D is also B’s father.
  3. Go down one generation. A is B’s daughter, so A is the child of D’s child, that is, D’s grandchild.
  4. Fix the gender. A is a daughter, so A is female.

A is D’s granddaughter, option (4).

Common slip. Answering from D’s side instead of A’s. The question asks what A is to D, so the answer must describe A, not D. Options (1) and (2) describe D.

ID 705108Q8. A block of marble $4\,\text{m}\times 3\,\text{m}\times 2\,\text{m}$ in size is cut into square tiles of $1$ m side having thickness of $10$ cm. Assuming there is no wastage in cutting, how many tiles will be made?
  1. 120
  2. 240
  3. 360
  4. 480
Show step-by-step solution

Answer: (2)

What is given. A block of volume $4\times3\times2$ cubic metres, cut with no wastage into tiles measuring $1\,\text{m}\times1\,\text{m}\times10\,\text{cm}$.
Idea used. With no wastage the total volume is conserved, so the count is simply the block volume divided by the tile volume. Convert every length to the same unit before dividing.
  1. Volume of the block. $4\times 3\times 2 = 24\ \text{m}^3$.
  2. Volume of one tile. The thickness is $10$ cm $= 0.1$ m, so the tile is $1\times 1\times 0.1 = 0.1\ \text{m}^3$.
  3. Divide. Number of tiles $=\dfrac{24}{0.1} = 240$.
  4. Sanity check on the cutting. The block is $4$ m $\times$ $3$ m $\times$ $2$ m, so it splits into $4\times3=12$ columns of base $1\,\text{m}\times1\,\text{m}$, each $2$ m tall, and each column gives $2/0.1 = 20$ tiles. That is $12\times 20 = 240$, so the tiling really is possible without waste.

240 tiles, option (2).

Common slip. Leaving the thickness in centimetres and dividing $24$ by $10$, or by $1\times1\times10$. Mixing metres with centimetres in one division is the usual source of the wrong options here.

ID 705109Q9. A lady walks one-tenth of the total distance at $3$ km/h, one-sixth she runs at $5$ km/h, one-fifth at $6$ km/h, and covers the remaining $16$ km at $16$ km/h by cycle. What is the total distance?
  1. 14 km
  2. 16 km
  3. 24 km
  4. 30 km
Show step-by-step solution

Answer: (4)

What is given. Fractions $\tfrac1{10}$, $\tfrac16$ and $\tfrac15$ of the journey are covered in three stages, and what is left over is $16$ km.
Idea used. The speeds are decoration here. Only the fractions matter: add them, subtract from $1$, and the leftover fraction equals the stated $16$ km.
  1. Add the three fractions. With denominator $30$, $$\frac1{10}+\frac16+\frac15=\frac{3}{30}+\frac{5}{30}+\frac{6}{30}=\frac{14}{30}=\frac{7}{15}.$$
  2. Find the leftover fraction. $1-\dfrac{7}{15}=\dfrac{8}{15}$ of the journey is covered by cycle.
  3. Equate to the given distance. If $D$ is the total distance, $\dfrac{8}{15}D = 16$.
  4. Solve. $D = 16\times\dfrac{15}{8} = 30$ km.

The total distance is 30 km, option (4).

Common slip. Being drawn into computing times for each leg. The four speeds are never needed; they are there to make the question look longer than it is.

ID 705110Q10. An OTP is made of six digits using 0 to 9. If three digits and their positions are known, what is the probability (in percentage) of discovering the full pin within 100 trials?
  1. $10\%$
  2. $20\%$
  3. $30\%$
  4. $40\%$
Show step-by-step solution

Answer: (1)

What is given. Six digit places; three of them are already known, together with where they sit. Up to $100$ distinct attempts are allowed.
Idea used. Only the unknown places generate possibilities. Trying $100$ different candidates out of $N$ equally likely ones succeeds with probability $100/N$, because the attempts are distinct and exactly one candidate is correct.
  1. Count the unknowns. Three positions remain, each of which can be any of the $10$ digits $0$ to $9$.
  2. Count the candidates. The number of possible OTPs consistent with what is known is $10^3 = 1000$, all equally likely.
  3. Count favourable trials. A sensible guesser never repeats a candidate, so $100$ trials cover $100$ distinct candidates out of $1000$, exactly one of which is right.
  4. Compute. Probability $=\dfrac{100}{1000}=0.1 = 10\%$.

The probability is $\mathbf{10\%}$, option (1).

Common slip. Counting $10^6$ possibilities and ignoring the three known digits, or repeating guesses at random, which would give $1-(1-\tfrac1{1000})^{100}\approx 9.5\%$ instead of the clean $10\%$ the question intends.

ID 705111Q11. Ramesh is taller than Rajesh but not taller than Rupesh. Suresh’s height is the average of the heights of Naresh and Rajesh. If Rajesh is taller than Naresh then who is the shortest among them?
  1. Suresh
  2. Naresh
  3. Rupesh
  4. Cannot be determined
Show step-by-step solution

Answer: (2)

What is given. Ramesh $>$ Rajesh; Ramesh $\le$ Rupesh; Suresh $=\tfrac12(\text{Naresh}+\text{Rajesh})$; Rajesh $>$ Naresh.
Idea used. The average of two distinct numbers lies strictly between them. That single fact places Suresh above Naresh and removes the only rival for last place.
  1. Place Suresh. Since Rajesh $>$ Naresh, the mean $\tfrac12(\text{Naresh}+\text{Rajesh})$ lies strictly between them, so $$\text{Naresh} < \text{Suresh} < \text{Rajesh}.$$
  2. Place Ramesh and Rupesh. The first sentence gives Rajesh $<$ Ramesh $\le$ Rupesh.
  3. Chain the inequalities. $$\text{Naresh} < \text{Suresh} < \text{Rajesh} < \text{Ramesh} \le \text{Rupesh}.$$
  4. Read off the minimum. Naresh sits at the bottom of the chain, and every comparison used is strict, so there is no ambiguity.

Naresh is the shortest, option (2).

Common slip. Choosing “cannot be determined” because Ramesh and Rupesh are only related by $\le$. That looseness sits at the tall end of the order and cannot affect who is shortest.

ID 705112Q12. The value of $\left(1-\frac{1}{2025}\right)\left(1-\frac{1}{2024}\right)\left(1-\frac{1}{2023}\right)\cdots\left(1-\frac{1}{2001}\right)$ is
  1. $\left(1-\frac{1}{79}\right)$
  2. $\left(1-\frac{1}{80}\right)$
  3. $\left(1-\frac{1}{81}\right)$
  4. $\left(1-\frac{1}{82}\right)$
Show step-by-step solution

Answer: (3)

What is given. A product of the terms $1-\frac1n$ for every integer $n$ from $2001$ to $2025$.
Idea used. Write each factor as $\frac{n-1}{n}$. Consecutive factors cancel, leaving only the first numerator and the last denominator.
  1. Rewrite each factor. $1-\dfrac1n=\dfrac{n-1}{n}$, so the product, taken in increasing order of $n$, is $$\frac{2000}{2001}\cdot\frac{2001}{2002}\cdot\frac{2002}{2003}\cdots\frac{2024}{2025}.$$
  2. Telescope. Every numerator after the first cancels the denominator before it, leaving $\dfrac{2000}{2025}$.
  3. Reduce. Both are divisible by $25$: $\dfrac{2000}{2025}=\dfrac{80}{81}$.
  4. Match the form of the options. $\dfrac{80}{81}=1-\dfrac{1}{81}$.

The product equals $1-\dfrac{1}{81}$, option (3).

Common slip. Miscounting the number of factors. There are $2025-2001+1=25$ of them, so the surviving numerator is $2000$, not $2001$; slipping by one gives $\tfrac{2001}{2025}$, which does not reduce to any option.

ID 705113Q13. One side and one diagonal of a rhombus are $13$ cm and $24$ cm, respectively. Then the area of the rhombus is
  1. $90\ \text{cm}^2$
  2. $100\ \text{cm}^2$
  3. $110\ \text{cm}^2$
  4. $120\ \text{cm}^2$
Show step-by-step solution

Answer: (4)

What is given. A rhombus of side $13$ cm with one diagonal equal to $24$ cm.
Idea used. The diagonals of a rhombus bisect each other at right angles, so each half-diagonal pair and a side form a right triangle. The area is half the product of the diagonals.
  1. Halve the known diagonal. The diagonals bisect each other, so half of the given diagonal is $24/2 = 12$ cm.
  2. Use the right triangle. A side of the rhombus is the hypotenuse of a right triangle whose legs are the two half-diagonals. With hypotenuse $13$ and one leg $12$, the other leg is $$\sqrt{13^2-12^2}=\sqrt{169-144}=\sqrt{25}=5.$$
  3. Recover the second diagonal. It is twice that leg: $2\times 5 = 10$ cm.
  4. Apply the area formula. $$\text{Area}=\tfrac12 d_1 d_2=\tfrac12(24)(10)=120\ \text{cm}^2.$$

The area is $120\ \text{cm}^2$, option (4).

Common slip. Using $\tfrac12(13)(24)$, which treats a side as though it were a diagonal, or forgetting to double the leg $5$ before applying the area formula.

ID 705114Q14. Two fair dice are thrown at random independently. What is the probability that the average of the values on their upper faces is $4$?
  1. $5/36$
  2. $1/6$
  3. $7/36$
  4. $2/9$
Show step-by-step solution

Answer: (1)

What is given. Two independent fair dice, so $36$ equally likely ordered outcomes.
Idea used. An average of $4$ for two numbers means their sum is $8$. Count the ordered pairs summing to $8$ and divide by $36$.
  1. Translate the condition. $\dfrac{a+b}{2}=4$ is the same as $a+b=8$.
  2. List the ordered pairs. $(2,6),(3,5),(4,4),(5,3),(6,2)$. Note $(1,7)$ is impossible since a die shows at most $6$.
  3. Count. That is $5$ favourable outcomes out of $36$ equally likely ones.
  4. Divide. The probability is $\dfrac{5}{36}$.

The probability is $\dfrac{5}{36}$, option (1).

Common slip. Counting $\{2,6\},\{3,5\},\{4,4\}$ as three unordered cases and dividing by $36$, or forgetting that $(4,4)$ occurs only once while $(2,6)$ and $(6,2)$ are two distinct outcomes.

ID 705115Q15. The square of the geometric mean of two positive integers is $30$. The smallest possible sum of the two integers is
  1. 10
  2. 11
  3. 13
  4. 17
Show step-by-step solution

Answer: (2)

What is given. Two positive integers $a$ and $b$ with $\left(\sqrt{ab}\right)^2 = ab = 30$.
Idea used. For a fixed product, the sum $a+b$ is smallest when the two factors are as close together as possible. Among integers that means the factor pair straddling $\sqrt{30}\approx 5.48$.
  1. Turn the condition into a product. The geometric mean of $a$ and $b$ is $\sqrt{ab}$, so its square is $ab = 30$.
  2. List the factor pairs of 30. $(1,30)$, $(2,15)$, $(3,10)$, $(5,6)$.
  3. Compute the sums. $31$, $17$, $13$ and $11$ respectively.
  4. Take the minimum. The smallest is $11$, from the pair $(5,6)$, which is indeed the pair closest together as the AM–GM reasoning predicts.

The smallest possible sum is 11, option (2).

Common slip. Applying AM $\ge$ GM to get $a+b\ge 2\sqrt{30}\approx 10.95$ and then answering $10$. That bound is not attained by integers; the least achievable integer sum is $11$.

ID 705116Q16. An electric heater uses approximately $1$ KWH for increasing temperature of $1$ L water by $1^\circ$C. If the heating element has a rating of $10$ KW, what is the time taken to raise the temperature of $1$ L water by $1\ ^\circ$C?
  1. 1 hour
  2. 15 mins
  3. 10 mins
  4. 6 mins
Show step-by-step solution

Answer: (4)

What is given. Energy required $=1$ kWh. Power available $=10$ kW.
Idea used. Energy $=$ power $\times$ time, so time $=$ energy $\div$ power. The unit kWh is built so that this division is immediate.
  1. Write the relation. $\text{time}=\dfrac{\text{energy}}{\text{power}}$.
  2. Substitute. $\text{time}=\dfrac{1\ \text{kWh}}{10\ \text{kW}} = 0.1\ \text{h}$.
  3. Convert to minutes. $0.1\times 60 = 6$ minutes.

It takes 6 minutes, option (4).

Common slip. Multiplying instead of dividing, or reading the $10$ kW rating as making the job ten times slower rather than ten times faster. A more powerful element delivers the same energy in less time.

ID 705117Q17. An experiment has collected data presented in an X–Y graph. The points oscillate about $Y=0$ with a period of roughly $2$ units, starting near $Y=1$ at $X=0$, and the size of the swings shrinks steadily as $X$ increases, so that by $X\approx 6$ they are barely visible. What would be the best function to fit the data? (for some positive constant $k$)
  1. $Y=\cos[kX]$
  2. $Y=\sin[kX^{2}]$
  3. $Y=\tan[kX^{3}]$
  4. $Y=e^{-x/k}\cos[kX]$
Show step-by-step solution

Answer: (4)

What is given. A scatter plot that oscillates regularly about zero while its amplitude decays towards zero, and which starts at a maximum near $Y=1$ when $X=0$.
Idea used. Read three features off the plot: the value at $X=0$, whether the oscillation is periodic, and whether the amplitude is constant or decaying. Each feature eliminates candidates.
  1. The amplitude decays. The swings get visibly smaller as $X$ grows, so the fitting function must carry a decaying factor. This alone rules out options (1), (2) and (3), all of which oscillate forever between fixed bounds or blow up.
  2. Check the start. At $X=0$ the data sit near $+1$. Since $e^{0}\cos 0 = 1$, option (4) starts at exactly $1$, whereas $\sin[kX^2]$ starts at $0$.
  3. Check the regularity. The zero crossings are evenly spaced, which matches $\cos[kX]$. In $\sin[kX^{2}]$ the crossings crowd together as $X$ grows, which the data do not do.
  4. Rule out the tangent. $\tan[kX^{3}]$ has vertical asymptotes and takes arbitrarily large values, while the data stay inside $[-1,1]$.

The damped cosine $Y=e^{-x/k}\cos[kX]$ is the fit, option (4).

Common slip. Choosing the plain cosine because the shape looks sinusoidal. A plain cosine keeps the same amplitude for ever; the shrinking envelope is the whole point of the question.

ID 705118Q18. Ten litre (L) milk contains $10\%$ water. How much water should be added to increase its proportion to $20\%$?
  1. 1 L
  2. 1.25 L
  3. 2 L
  4. 2.25 L
Show step-by-step solution

Answer: (2)

What is given. A $10$ L mixture that is $10\%$ water, so $1$ L water and $9$ L pure milk. Water is added; no milk is added or removed.
Idea used. The quantity of pure milk is unchanged by the addition, so it is easiest to track the milk, whose share falls from $90\%$ to $80\%$.
  1. Split the original mixture. Water $=10\%$ of $10 = 1$ L; milk $=9$ L.
  2. Let $x$ be the water added. The new total is $10+x$ litres and the new water content is $1+x$ litres.
  3. Impose the required proportion. $$\frac{1+x}{10+x}=\frac{20}{100}=\frac15.$$
  4. Solve. $5(1+x) = 10+x$, so $5+5x = 10+x$, giving $4x = 5$ and $x = 1.25$ L.
  5. Check with the milk. Milk stays at $9$ L and must become $80\%$ of the total, so the total is $9/0.8 = 11.25$ L, an increase of exactly $1.25$ L.

Add 1.25 L of water, option (2).

Common slip. Adding $10\%$ of $10$ litres, that is $1$ L, on the grounds that the proportion must rise by ten percentage points. Diluting also enlarges the denominator, so more than $1$ L is needed.

ID 705119Q19. If Asha’s mother is Tanisha’s daughter’s aunt and Tanisha has no nephew, then Asha is Tanisha’s
  1. mother
  2. niece
  3. grand mother
  4. sister
Show step-by-step solution

Answer: (2)

What is given. Asha’s mother is an aunt of Tanisha’s daughter, and Tanisha has no nephew.
Idea used. An aunt of a child is a sister of one of the child’s parents. Fixing which parent, and then using the “no nephew” clause to fix Asha’s gender, pins the answer down.
  1. Name the people. Let $T$ be Tanisha, $D$ her daughter, and $M$ Asha’s mother. We are told $M$ is $D$’s aunt.
  2. Identify $M$. An aunt of $D$ is a sister of one of $D$’s parents, and $T$ is $D$’s mother. So $M$ is $T$’s sister.
  3. Place Asha. Asha is $M$’s child, so Asha is the child of Tanisha’s sister, that is, Tanisha’s nephew or niece.
  4. Use the extra clue. Tanisha has no nephew, so Asha cannot be male. Asha is therefore Tanisha’s niece.

Asha is Tanisha’s niece, option (2).

Common slip. Ignoring the “no nephew” clause. It is not decoration: the name Asha is used for both men and women, and that clause is what forces the female relation.

ID 705120Q20. A chocolate bar of $5$ cm length and $4$ cm width has to be cut into $1\ \text{cm}\times 1\ \text{cm}$ pieces. How many minimum cuts would be required, if pieces are to be taken one-by-one? (One can start by cutting along either length or width, before removing $1\ \text{cm}\times1\ \text{cm}$ pieces one by one)
  1. 20
  2. 19
  3. 18
  4. 10
Show step-by-step solution

Answer: (2)

What is given. A $5\times4$ bar to be reduced to twenty $1\times1$ squares, cutting one piece at a time so that each cut separates a single piece into two.
Idea used. Count pieces, not cuts. Every cut acts on exactly one piece and turns it into two, so each cut raises the number of pieces by exactly one, whatever route you take.
  1. Set up the invariant. Start with $1$ piece. A cut splits one piece into two, so after $c$ cuts there are exactly $1+c$ pieces. This holds no matter where the cuts are made.
  2. Count the target pieces. A $5\ \text{cm}\times4\ \text{cm}$ bar yields $5\times4=20$ unit squares.
  3. Solve for the number of cuts. $1+c = 20$ gives $c = 19$, and this is forced, so $19$ is both the minimum and the maximum.
  4. Confirm with an explicit route. Four cuts split the bar into five $1\times 4$ strips; each strip then needs three cuts to give four squares, that is $5\times 3=15$. Total $4+15=19$.

Exactly 19 cuts, option (2).

Common slip. Answering $10$ by imagining full-width cuts that pass through several pieces at once. The question fixes cuts that take pieces off one by one, so no cut can split two pieces simultaneously.

ID 706501Q21. Let $A, B$ be two non-empty subsets of $\mathbb{R}$. Let $$S=\{f:A\to\mathbb{R}\mid f\text{ is continuous}\},\quad T=\{f:B\to\mathbb{R}\mid f\text{ is continuous}\},\quad U=\{f:A\times A\to\mathbb{R}\mid f\text{ is continuous}\}.$$ Which of the following statements is true?
  1. If $A$ is finite, then there exists a bijection between $S$ and $U$.
  2. If $A$ is finite and $B=[0,1]$, then there is no bijection between $S$ and $T$.
  3. There is no bijection between $S$ and $U$ for any choice of $A$.
  4. If $A\neq B$, then there is no bijection between $T$ and $U$.
Show step-by-step solution

Answer: (1)

What is given. $A,B\subseteq\mathbb{R}$ non-empty, each carrying the subspace topology, and $S,T,U$ the sets of real-valued continuous functions on $A$, $B$ and $A\times A$.
Idea used. A bijection between two sets exists precisely when they have the same cardinality. A finite subset of $\mathbb{R}$ is discrete, so every function on it is continuous, and a continuous function on a separable space is determined by its values on a countable dense subset.
  1. A finite set is discrete. If $|A| = n < \infty$, every point of $A$ is isolated in the subspace topology, so every function $A\to\mathbb{R}$ is continuous. Hence $S$ is in bijection with $\mathbb{R}^{n}$ and $|S| = \mathfrak{c}^{\,n} = \mathfrak{c}$.
  2. Do the same for $A\times A$. It is finite with $n^{2}$ points and also discrete, so $U$ is in bijection with $\mathbb{R}^{n^{2}}$ and $|U| = \mathfrak{c}^{\,n^{2}} = \mathfrak{c}$.
  3. Conclude for option (1). $|S| = |U| = \mathfrak{c}$, so a bijection between $S$ and $U$ exists. Statement (1) is true, and statement (3), which denies this for every $A$, is false.
  4. Dispose of option (2). $B=[0,1]$ is separable, and a continuous function on it is determined by its values on $\mathbb{Q}\cap[0,1]$, so $|T|\le\mathfrak{c}^{\aleph_0}=\mathfrak{c}$. The constants give $|T|\ge\mathfrak{c}$, hence $|T|=\mathfrak{c}=|S|$ and a bijection does exist. Statement (2) is false.
  5. Dispose of option (4). Take $A=B=\{0\}$ — or any $A\ne B$ with both finite — and both $T$ and $U$ again have cardinality $\mathfrak{c}$. Sets being unequal says nothing about their cardinalities, so statement (4) is false.

Only statement (1) holds, so the answer is option (1).

Common slip. Treating $S$ and $U$ as topological or vector-space objects and looking for a continuous or linear bijection. The question asks only for a bijection of sets, so the whole problem is a cardinality count.

ID 706502Q22. Let $(x_n)_{n\ge 1}$ be a sequence of real numbers that has a decreasing subsequence $(x_{n_k})_{k\ge 1}$. Assume that $$\lim_{k\to\infty} x_{n_k} = 2025.$$ Which of the following statements is necessarily true?
  1. $\displaystyle\liminf_{n\to\infty} x_n \ge 2025$
  2. $\displaystyle\limsup_{n\to\infty} x_n \le 2025$
  3. $\displaystyle\liminf_{n\to\infty} x_n \le 2025$
  4. $\displaystyle\liminf_{k\to\infty} x_{n_k} > 2025$
Show step-by-step solution

Answer: (3)

What is given. Nothing about $(x_n)$ except that one of its subsequences is decreasing and tends to $2025$. The other terms are completely unconstrained.
Idea used. $\liminf_{n} x_n$ is the smallest subsequential limit and $\limsup_n x_n$ the largest. So every subsequential limit $L$ satisfies $\liminf x_n \le L \le \limsup x_n$. Only the inequality pointing the right way survives.
  1. Locate 2025 among the subsequential limits. Since $x_{n_k}\to 2025$, the value $2025$ is a subsequential limit of $(x_n)$.
  2. Apply the extremal characterisation. The limit inferior is the infimum of the set of subsequential limits, so $\liminf_{n\to\infty} x_n \le 2025$. That is exactly statement (3), and it needed no extra hypothesis.
  3. Kill statement (1) with an example. Put $x_n = 2025 + \tfrac1n$ for even $n$ and $x_n = -n$ for odd $n$. The even-indexed terms form a decreasing subsequence tending to $2025$, yet $\liminf x_n = -\infty$.
  4. Kill statement (2) the same way. Put $x_n = 2025+\tfrac1n$ for even $n$ and $x_n = n$ for odd $n$. The hypothesis still holds but $\limsup x_n = +\infty$.
  5. Kill statement (4). The subsequence converges, so $\liminf_{k} x_{n_k} = \lim_k x_{n_k} = 2025$, which is not strictly greater than $2025$.

Only statement (3) is forced, so the answer is option (3).

Common slip. Reasoning that a decreasing subsequence with limit $2025$ has all its terms $\ge 2025$, and concluding that the whole sequence is bounded below by $2025$. The hypothesis controls one subsequence only; every other term is free.

ID 706503Q23. Consider the sequences $(a_n)_{n\ge1}$ and $(b_n)_{n\ge1}$, defined by $$a_n = -2\sqrt{n} + \sum_{k=1}^{n}\frac{1}{\sqrt{k}} \quad\text{and}\quad b_n = -2\sqrt{n+1} + \sum_{k=1}^{n}\frac{1}{\sqrt{k}}.$$ Which of the following statements is true?
  1. $(a_n)_{n\ge1}$ converges but $(b_n)_{n\ge1}$ does not converge.
  2. $(b_n)_{n\ge1}$ converges but $(a_n)_{n\ge1}$ does not converge.
  3. Both $(a_n)_{n\ge1}$ and $(b_n)_{n\ge1}$ converge.
  4. Neither $(a_n)_{n\ge1}$ nor $(b_n)_{n\ge1}$ converges.
Show step-by-step solution

Answer: (3)

What is given. The same partial sum $\sum_{k\le n} k^{-1/2}$ corrected by $-2\sqrt n$ in one case and by $-2\sqrt{n+1}$ in the other.
Idea used. $2\sqrt n$ is the integral approximation to $\sum_{k\le n}k^{-1/2}$, so both sequences measure the same error term. Show one is decreasing, the other increasing, and that they squeeze each other; monotone plus bounded gives convergence.
  1. The two sequences differ by a null term. $$a_n-b_n = 2\sqrt{n+1}-2\sqrt n = \frac{2}{\sqrt{n+1}+\sqrt n}\longrightarrow 0 .$$ So they converge or diverge together, which already rules out options (1) and (2).
  2. $(a_n)$ is decreasing. $$a_{n+1}-a_n=\frac{1}{\sqrt{n+1}}-2\bigl(\sqrt{n+1}-\sqrt n\bigr)=\frac{1}{\sqrt{n+1}}-\frac{2}{\sqrt{n+1}+\sqrt n}.$$ Since $\sqrt{n+1}+\sqrt n < 2\sqrt{n+1}$, the subtracted fraction exceeds $\tfrac1{\sqrt{n+1}}$, so $a_{n+1}-a_n<0$.
  3. $(b_n)$ is increasing. $$b_{n+1}-b_n=\frac{1}{\sqrt{n+1}}-\frac{2}{\sqrt{n+2}+\sqrt{n+1}},$$ and now $\sqrt{n+2}+\sqrt{n+1} > 2\sqrt{n+1}$, so the subtracted fraction is smaller than $\tfrac1{\sqrt{n+1}}$ and $b_{n+1}-b_n>0$.
  4. They bound each other. From step 1, $a_n > b_n$ for every $n$. Hence $a_n > b_n \ge b_1 = 1-2\sqrt2$, so the decreasing sequence $(a_n)$ is bounded below; and $b_n < a_n \le a_1 = -1$, so the increasing sequence $(b_n)$ is bounded above.
  5. Apply monotone convergence. A decreasing sequence bounded below converges, and an increasing sequence bounded above converges. Both limits are equal, since $a_n-b_n\to0$; the common value is $\zeta(1/2)\approx -1.4604$.

Both sequences converge, option (3).

Common slip. Noticing that $\sum k^{-1/2}$ diverges and concluding that both sequences diverge. The subtracted term $2\sqrt n$ diverges at exactly the same rate; what is left over is the bounded error of the integral approximation.

ID 706504Q24. Let $f:\mathbb{R}\to\mathbb{R}$ be a non-constant continuous function. Which of the following statements is necessarily true?
  1. For every bounded subset $A\subseteq\mathbb{R}$, $f^{-1}(A)$ is a bounded subset of $\mathbb{R}$.
  2. For every Cauchy sequence $(x_n)_{n\ge1}$ in $\mathbb{R}$, $(f(x_n))_{n\ge1}$ is a Cauchy sequence in $\mathbb{R}$.
  3. There exists $x\in\mathbb{R}$ such that $f(x)=x$.
  4. There exists $x\in\mathbb{R}$ such that $f(x)=0$.
Show step-by-step solution

Answer: (2)

What is given. Only that $f$ is continuous on all of $\mathbb{R}$ and not constant.
Idea used. $\mathbb{R}$ is complete, so a Cauchy sequence is exactly a convergent one. Continuity then carries convergence across, and the image sequence converges, hence is Cauchy. The other three options each fail on a one-line example.
  1. Prove statement (2). Let $(x_n)$ be Cauchy in $\mathbb{R}$. By completeness $x_n\to x$ for some $x\in\mathbb{R}$. Continuity of $f$ at $x$ gives $f(x_n)\to f(x)$, and a convergent sequence in $\mathbb{R}$ is Cauchy.
  2. Refute (1). Take $f(x)=\sin x$, which is continuous and non-constant. With $A=[-1,1]$, bounded, $f^{-1}(A)=\mathbb{R}$ is unbounded.
  3. Refute (3). Take $f(x)=x+1$. It is continuous and non-constant, and $f(x)=x$ would force $1=0$.
  4. Refute (4). Take $f(x)=e^{x}$, continuous and non-constant, which is strictly positive everywhere.

Only statement (2) is necessarily true, option (2).

Common slip. Assuming a Cauchy sequence must be handled by uniform continuity, which is the right instinct on a general metric space. On $\mathbb{R}$ completeness makes plain continuity enough, because the sequence already has a limit inside the domain.

ID 706505Q25. Let $f:\mathbb{R}\to[0,\infty)$ be a bijective function. Which of the following statements is true?
  1. $f$ is monotone.
  2. $f$ is continuous but not strictly monotone.
  3. $f$ is not continuous.
  4. $f$ is continuous but not uniformly continuous.
Show step-by-step solution

Answer: (3)

What is given. $f$ is a bijection from the open line $\mathbb{R}$ onto the half-line $[0,\infty)$, which contains its endpoint $0$.
Idea used. A continuous injection on an interval is strictly monotone, and a strictly monotone continuous map sends the open interval $\mathbb{R}$ onto an open interval. Since $[0,\infty)$ is not open in $\mathbb{R}$, no such $f$ can be continuous.
  1. Suppose $f$ were continuous. Being a bijection it is injective, and a continuous injective function on an interval is strictly monotone. This is the intermediate value theorem applied to any three points that would violate monotonicity.
  2. Identify the image. If $f$ is strictly increasing and continuous on $\mathbb{R}$, then $$f(\mathbb{R}) = \Bigl(\lim_{x\to-\infty}f(x),\ \lim_{x\to+\infty}f(x)\Bigr),$$ an open interval (allowing $\pm\infty$ as endpoints). The strictly decreasing case is the same with the ends swapped.
  3. Compare with the target. $[0,\infty)$ contains its left endpoint $0$, so it is not an open interval. Hence a continuous bijection $\mathbb{R}\to[0,\infty)$ cannot exist, and options (2) and (4) are impossible.
  4. Rule out monotonicity as well. A monotone bijection would attain $0$ at some $x_0$; if $f$ were increasing then $f(x)<0$ for $x<x_0$, contradicting $f\ge 0$, and the decreasing case fails symmetrically. So statement (1) is false too.
  5. Confirm that a bijection does exist. Bijections $\mathbb{R}\to[0,\infty)$ exist in abundance, since both sets have cardinality $\mathfrak{c}$; they simply cannot be continuous.

Any such $f$ fails to be continuous, option (3).

Common slip. Trying to build the map from $|x|$ or $x^{2}$, which are continuous onto $[0,\infty)$ but two-to-one. Surjectivity is easy and injectivity is easy; it is having both together with continuity that is impossible.

ID 706506Q26. Consider the sequences $(f_n)_{n\ge1}$ and $(g_n)_{n\ge1}$ of functions defined on the interval $[-1,1]$ by $$f_n(x)=(-1)^n\,\frac{x^2+n}{n^2}\quad\text{and}\quad g_n(x)=(-1)^n\,\frac{x^2+n^2}{n^3}.$$ Which of the following statements is true?
  1. $\sum_{n\ge1} f_n$ and $\sum_{n\ge1} g_n$ are uniformly convergent on the interval $[-1,1]$.
  2. $\sum_{n\ge1} f_n$ is uniformly convergent on the interval $[-1,1]$, but $\sum_{n\ge1} g_n$ is not.
  3. $\sum_{n\ge1} g_n$ is uniformly convergent on the interval $[-1,1]$, but $\sum_{n\ge1} f_n$ is not.
  4. Neither $\sum_{n\ge1} f_n$ nor $\sum_{n\ge1} g_n$ is uniformly convergent on the interval $[-1,1]$.
Show step-by-step solution

Answer: (1)

What is given. Two series of functions on $[-1,1]$, each with an alternating sign and a numerator that mixes an $x$-dependent term with a constant one.
Idea used. Split each term into an $x$-dependent piece and a piece free of $x$. The $x$-dependent piece yields to the Weierstrass $M$-test; the $x$-free piece is a numerical series, for which uniform convergence and ordinary convergence are the same thing.
  1. Split the terms. $$f_n(x)=(-1)^n\frac{x^2}{n^2}+\frac{(-1)^n}{n},\qquad g_n(x)=(-1)^n\frac{x^2}{n^3}+\frac{(-1)^n}{n}.$$ Both carry the same tail $\frac{(-1)^n}{n}$.
  2. Handle the $x$-dependent pieces. On $[-1,1]$ we have $x^2\le1$, so $\bigl|(-1)^n x^2/n^2\bigr|\le 1/n^2$ and $\bigl|(-1)^n x^2/n^3\bigr|\le 1/n^3$. Since $\sum 1/n^2$ and $\sum 1/n^3$ converge, the Weierstrass $M$-test gives uniform convergence of both pieces on $[-1,1]$.
  3. Handle the constant piece. $\sum_{n\ge1}\frac{(-1)^n}{n}$ converges by the alternating series test, to $-\ln 2$. Its terms do not involve $x$, so the supremum of its tail over $[-1,1]$ is just the size of the tail, which tends to $0$. Uniform convergence follows.
  4. Recombine. A sum of two uniformly convergent series is uniformly convergent, so both $\sum f_n$ and $\sum g_n$ converge uniformly on $[-1,1]$.

Both series converge uniformly, option (1).

Common slip. Applying the $M$-test to the whole term. Then $\sup_{[-1,1]}|f_n| = (1+n)/n^2 \sim 1/n$ and $\sum 1/n$ diverges, so the test is inconclusive — but inconclusive is not the same as false. Splitting off the alternating harmonic part is what settles it.

ID 706507Q27. Let $V$ be a vector space over $\mathbb{R}$. Let $T_1, T_2 : V\to V$ be two $\mathbb{R}$-linear transformations such that $T_1+T_2$ and $T_1-T_2$ are linearly independent over $\mathbb{R}$. Consider the following statements:
(A) The transformations $T_1$ and $T_2$ are linearly independent over $\mathbb{R}$.
(B) There exist $\mathbb{R}$-linear transformations $T_3, T_4 : V\to V$ such that $\{T_1+T_2,\ T_1-T_2,\ T_3,\ T_4\}$ is linearly independent over $\mathbb{R}$.
Which of the following statements is true?
  1. (A) is true but (B) is false.
  2. (B) is true but (A) is false.
  3. Both (A) and (B) are true.
  4. Both (A) and (B) are false.
Show step-by-step solution

Answer: (3)

What is given. $T_1+T_2$ and $T_1-T_2$ are independent elements of the vector space $\operatorname{End}_{\mathbb{R}}(V)$ of linear maps $V\to V$.
Idea used. Work inside $\operatorname{End}(V)$, which is itself a real vector space. The pair $T_1\pm T_2$ spans the same subspace as $T_1,T_2$, and the existence of two independent operators forces $\dim V\ge2$, hence $\dim\operatorname{End}(V)\ge4$.
  1. Statement (A): compare the spans. Both $T_1+T_2$ and $T_1-T_2$ lie in $W=\operatorname{span}\{T_1,T_2\}$, so $\operatorname{span}\{T_1+T_2,\,T_1-T_2\}\subseteq W$.
  2. Force the dimension up. The hypothesis says the left-hand span has dimension $2$, so $\dim W\ge 2$. But $W$ is spanned by two elements, so $\dim W = 2$ exactly, which means $T_1$ and $T_2$ are linearly independent. Statement (A) is true.
  3. Statement (B): bound $\dim V$ from below. If $\dim V=1$ then $\operatorname{End}(V)\cong\mathbb{R}$ has dimension $1$ and cannot contain two independent elements. So $\dim V\ge2$, taking $\dim V=\infty$ as allowed.
  4. Bound $\dim\operatorname{End}(V)$. For finite $\dim V=n\ge2$, $\dim\operatorname{End}(V)=n^{2}\ge4$; for infinite-dimensional $V$, $\operatorname{End}(V)$ is infinite-dimensional. Either way $\dim\operatorname{End}(V)\ge 4$.
  5. Extend the independent set. In a vector space of dimension at least $4$, any linearly independent set of size $2$ extends to one of size $4$. Choosing $T_3,T_4$ from such an extension proves statement (B).

Both statements hold, option (3).

Common slip. Trying to build $T_3,T_4$ explicitly without first checking that $\operatorname{End}(V)$ is big enough. The whole content of (B) is the dimension count $n^2\ge4$; once that is in hand, the extension is standard.

ID 706508Q28. Let $T:\mathbb{R}^4\to\mathbb{R}^4$ be an $\mathbb{R}$-linear transformation such that $$(T^2+T+I)(T-2I)=0 \quad\text{and}\quad (T^2+T+2I)(T^2-4I)=0.$$ Which of the following statements is FALSE?
  1. $T$ is diagonalizable over $\mathbb{R}$.
  2. The characteristic polynomial of $T$ is $(x-2)^4$.
  3. The characteristic polynomial of $T$ is $(x^2+x+2)(x^2-4)$.
  4. For every $\mathbb{R}$-linear transformation $S:\mathbb{R}^4\to\mathbb{R}^4$, we have $ST=TS$.
Show step-by-step solution

Answer: (3)

What is given. Two polynomials annihilate $T$: $p_1(x)=(x^2+x+1)(x-2)$ and $p_2(x)=(x^2+x+2)(x^2-4)$.
Idea used. The minimal polynomial divides every annihilating polynomial, so it divides their greatest common divisor. Computing that gcd pins $T$ down completely.
  1. Factor both annihilators. $p_1(x)=(x^2+x+1)(x-2)$ and $p_2(x)=(x^2+x+2)(x-2)(x+2)$.
  2. Check the quadratics. $x^2+x+1$ has discriminant $1-4=-3<0$ and $x^2+x+2$ has discriminant $1-8=-7<0$, so both are irreducible over $\mathbb{R}$, and being distinct they are coprime.
  3. Test the remaining linear factor. Does $x+2$ divide $p_1$? Substituting $x=-2$ gives $(4-2+1)(-2-2)=3\cdot(-4)=-12\neq0$, so it does not.
  4. Take the gcd. The only common factor is $x-2$, so $\gcd(p_1,p_2)=x-2$. The minimal polynomial divides it and is non-constant, hence $m_T(x)=x-2$, which means $T-2I=0$, that is $T=2I$.
  5. Test the four statements against $T=2I$. (1) $2I$ is already diagonal, so it is diagonalizable: true. (2) Its characteristic polynomial is $\det(xI-2I)=(x-2)^4$: true. (4) A scalar multiple of the identity commutes with every $S$: true. (3) $(x^2+x+2)(x^2-4)$ is not $(x-2)^4$, for instance it has $-2$ as a root while $(x-2)^4$ does not: false.

Statement (3) is the false one, so the answer is option (3).

Common slip. Reading the two hypotheses as separate possibilities and concluding that the characteristic polynomial could be either $(x-2)^4$ or $(x^2+x+2)(x^2-4)$. Both equations hold simultaneously, so the minimal polynomial must divide the gcd, not just one of them.
